# 🚀 Angular в Docker с Hot Reload - Готово к использованию!

## ✅ Что настроено

Ваше Angular приложение теперь полностью настроено для разработки в Docker с автоматической пересборкой!

### Созданные файлы:
- `Dockerfile.dev` - Dockerfile для разработки
- `docker-compose.dev.yml` - конфигурация Docker Compose для разработки  
- `scripts/dev-docker.sh` - удобный скрипт для запуска
- `QUICK_START.md` - краткая инструкция
- `DOCKER_DEV_README.md` - подробная документация

## 🎯 Как использовать

### Быстрый запуск:
```bash
./scripts/dev-docker.sh
```

### Ручной запуск:
```bash
docker compose -f docker-compose.dev.yml up --build
```

### Остановка:
```bash
docker compose -f docker-compose.dev.yml down
```

## 🔥 Hot Reload работает!

При изменении любого файла в папке `src/`:
1. ✅ Angular dev server автоматически обнаружит изменения
2. ✅ Произойдет пересборка приложения  
3. ✅ Браузер автоматически обновится

## 🌐 Доступ к приложению

После запуска приложение доступно по адресу:
**http://localhost:4200**

## 📝 Преимущества

- ✅ **Изолированная среда** - все зависимости в Docker
- ✅ **Быстрая разработка** - без установки Node.js локально
- ✅ **Автоматическая пересборка** - при изменении кода
- ✅ **Hot reload** - браузер обновляется автоматически
- ✅ **Консистентная среда** - одинаково работает на всех машинах

## 🛠️ Технические детали

### Dockerfile.dev
- Использует Node.js 20 Alpine
- Устанавливает Angular CLI 14.2.12
- Запускает `ng serve` с параметрами для Docker

### docker-compose.dev.yml  
- Монтирует исходный код через volumes
- Исключает `node_modules` для избежания конфликтов
- Настраивает порт 4200
- Включает все переменные окружения

### Hot Reload
- Использует `--poll 2000` для проверки изменений каждые 2 секунды
- `--host 0.0.0.0` для доступа извне контейнера
- `--disable-host-check` для работы в Docker

## 🚨 Troubleshooting

### Проблема: Порт занят
```bash
# Измените порт в docker-compose.dev.yml
ports:
  - '4201:4200'  # вместо 4200:4200
```

### Проблема: Изменения не отражаются
- Убедитесь, что файлы изменяются в папке `src/`
- Проверьте логи: `docker logs ph-ee-operations-web-phee-web-app-dev-1`

### Проблема: Медленная сборка
- Первая сборка всегда медленная
- Последующие сборки будут быстрее
