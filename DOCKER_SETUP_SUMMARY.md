## 🚀 Как использовать

### Запуск:
```bash
./scripts/dev-docker.sh
```

### Остановка:
```bash
docker compose -f docker-compose.dev.yml down
```

## 🔥 Hot Reload в действии

При изменении любого файла в папке `src/`:
1. Angular dev server автоматически обнаружит изменения
2. Произойдет пересборка приложения (обычно 2-3 секунды)
3. Браузер автоматически обновится
