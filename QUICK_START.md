# 🚀 Быстрый старт - Angular в Docker с Hot Reload

## Запуск в режиме разработки

```bash
# 1. Убедитесь, что Docker запущен
docker info

# 2. Запустите приложение с hot reload
./scripts/dev-docker.sh

# 3. Откройте браузер
open http://localhost:4200
```

## Что происходит

✅ **Автоматическая пересборка** - при изменении любого файла в `src/`  
✅ **Hot reload** - браузер обновляется автоматически  
✅ **Изолированная среда** - все зависимости в Docker  
✅ **Быстрая разработка** - без установки Node.js локально  

## Остановка

```bash
# Остановить контейнеры
docker compose -f docker-compose.dev.yml down
```

## Проблемы?

- **Порт занят**: измените порт в `docker-compose.dev.yml` (4201:4200)
- **Изменения не отражаются**: убедитесь, что файлы в папке `src/`
- **Медленная сборка**: это нормально для первого запуска
